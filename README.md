## CosM — Computation Strategy Machine

CosM is a custom chess engine designed to play **Cosmic Chess** — a collection of dynamic, rule-altering chess variants aimed at making the game more engaging and unpredictable.

---

## Overview

Unlike traditional engines focused solely on standard chess, CosM is built to support:

- Custom piece behavior  
- Variant-specific rules  
- Non-standard board mechanics  
- Experimental gameplay systems  

The goal is to create an engine that can adapt to **entirely new forms of chess**, not just optimize within existing ones.

---

## Features

- Bitboard-based architecture  
- Efficient move generation  
- Designed for variant flexibility  
- Modular logic for custom rules and pieces  

---

## Vision

CosM is part of a broader project: **Cosmic Chess** — a game that explores new dimensions of chess through:

- Themed variants (e.g., futuristic, magical, chaotic)  
- New pieces and mechanics  
- Enhanced visual and gameplay experience
